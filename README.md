# Web Notes

A personal knowledge base for web development.

This project contains my notes and references for HTML, CSS, JavaScript, and other web development topics. It is built as a lightweight documentation website using Markdown files and JavaScript.

## Features

- 📚 Organized documentation by topic
- 📝 Markdown-based content
- ⚡ Lightweight and fast
- 🌐 Hosted with GitHub Pages

## Technologies

- HTML5
- CSS3
- JavaScript
- Markdown
