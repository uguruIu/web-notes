# CSS Introduction

## Overview

CSS (Cascading Style Sheets), web sayfalarının görünümünü ve düzenini tanımlamak için kullanılan stil dilidir.

HTML sayfanın yapısını oluştururken, CSS bu yapının nasıl görüneceğini belirler.

---

## HTML, CSS, JavaScript

Web geliştirmede:

- HTML → Structure
- CSS → Presentation
- JavaScript → Interaction

olarak kullanılır.

---

## What Can CSS Do?

CSS ile;

- Change colors
- Set fonts
- Add spacing
- Create layouts
- Build responsive designs
- Add animations and transitions
- Improve user experience

gibi işlemler yapılabilir.

---

## Basic Example

### HTML

```html
<h1>Hello World</h1>

<p>Welcome to CSS.</p>
```

### CSS

```css
h1 {
    color: steelblue;
}

p {
    color: gray;
}
```

---

## CSS Versions

- CSS1 (1996)
- CSS2 (1998)
- CSS3 (Modular specification)
- Modern CSS (Variables, Flexbox, Grid, etc.)

Today, CSS is developed as independent modules instead of a single version.

---

## Advantages of CSS

- Separates content from presentation
- Makes websites easier to maintain
- Reduces duplicated code
- Improves consistency
- Supports responsive design
- Works across modern browsers
