# HTML Introduction

## Overview

HTML (HyperText Markup Language), web sayfalarının yapısını oluşturmak için kullanılan işaretleme dilidir.

HTML bir programlama dili değildir. İçeriğin yapısını tanımlamak için kullanılır.

---

## HTML, CSS, JavaScript

Web geliştirmede:

- HTML → Yapı
- CSS → Tasarım
- JavaScript → Etkileşim

olarak kullanılır.

---

## Basic Example

```html
<!DOCTYPE html>
<html>
<body>

<h1>Hello World</h1>

<p>My first HTML page.</p>

</body>
</html>
